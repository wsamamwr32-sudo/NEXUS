# Permissions Matrix\n\nScopes: Tenant → Organization → Workspace → Team → User → Resource → Action.\n\nEvery endpoint/action must answer: who, action, resource, tenant/workspace, relationship/permission, risk class, approval requirement.\n\nHigh-risk: organization deletion, bulk delete, credential rotation, ownership change, auth disablement, backup restore, purge, privileged automation, external integration mutation.\n\nServer-side enforcement is mandatory.\n
