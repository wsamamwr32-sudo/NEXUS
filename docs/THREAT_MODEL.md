# Threat Model\n\nTrust boundaries: user/device→client; client→API; API→domain; app→database/object storage; app→external integrations; AI→retrieved content/tools; CI→artifacts.\n\nPriority threats: cross-tenant access/BOLA; broken authentication/session; privilege escalation; prompt injection; sensitive-data leakage; SSRF; malicious uploads; replayed webhooks; resource exhaustion/retry storms; supply-chain compromise; client clock manipulation; backup corruption.\n\nStrategy: application authorization + database/object authorization + audit + rate limits + schema validation + AI tool risk policies + artifact provenance/integrity.\n
