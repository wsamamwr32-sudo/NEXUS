# NEXUS Architecture\n\n## Decision\nModular Monolith + asynchronous boundaries + explicit adapters.\n\n## Layers\nClients → Gateway/API → Application → Domain → Data → Infrastructure\n                                     ↘ Integration / AI / Automation / Observability / Security\n\n## Domain independence\nDomain logic cannot directly depend on React, Android UI, PostgreSQL drivers, Redis, AI vendors, GitHub APIs or cloud SDKs.\n\n## Modules\nidentity, tenancy, permissions, goals, execution, planning, calendar, time, crm, support, knowledge, collaboration, sync, automation, ai, integrations, plugins, analytics, audit, incidents, platform.\n\nA service boundary requires an ADR backed by measured operational evidence.\n
