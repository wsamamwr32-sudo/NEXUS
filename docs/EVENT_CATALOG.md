# Event Catalog\n\nEnvelope: event_id, event_type, version, occurred_at, tenant_id, actor_id, correlation_id, causation_id, payload.\n\nFamilies: TASK_*, PROJECT_*, MILESTONE_*, CUSTOMER_*, TICKET_*, DOCUMENT_*, WORKFLOW_*, AI_*, SYNC_*, SECURITY_*, INCIDENT_*.\n\nUse transactional outbox semantics where a domain transaction must publish an event. Consumers tolerate duplicates and permitted reordering.\n
