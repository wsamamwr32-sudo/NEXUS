# NEXUS Requirements\n\n1. Product foundation: organizations, workspaces, memberships, roles, permissions, audit.\n2. Execution graph: goals, objectives, programs, projects, milestones, tasks, dependencies.\n3. Planning: capacity, availability, calendars, focus sessions, explainable recommendations.\n4. Collaboration: comments, mentions, realtime state, conflict handling.\n5. Offline: local reads/writes, sync queue, deduplication, retries, conflict resolution.\n6. CRM/support: customers, companies, contacts, opportunities, tickets, conversations, SLA/escalation.\n7. Knowledge: documents, versions, folders, tags, attachments, search, citations.\n8. Automation: triggers, conditions, actions, retries, compensation, durable execution.\n9. AI: model gateway, RAG, agents, tools, permissions, approvals, budget, evaluation, fallback.\n10. Integrations/plugins/MCP, analytics, reliability, security, delivery, accessibility and localization.\n\nCompletion requires implementation evidence plus verification evidence.\n
